= アプリケーションのスナップショットを削除します
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/appSnaps/{appSnap_id}`#

指定されたアプリケーションスナップショットAPIリソースを削除します。

*副作用*

* スナップショットが進行中の場合、スナップショットはキャンセルされます。
* スナップショットが完了すると、スナップショットデータは削除されます。




== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}




| app_id | string | path（パス） | True  a| 
含まれるアプリリソースのID



| appSnap_id | string | path（パス） | True  a| 
リストするappSnapコレクションのID

|===

Status: 204, Indicates if the appSnap resource was deleted.
