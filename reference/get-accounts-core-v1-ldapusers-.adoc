= LDAPユーザーを取得する
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/ldapUsers/{ldapUser_id}`#

保存されているLDAPリソースを表すJSONオブジェクトを返します。



[[parameters]]
== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}




| ldapUser_id | string | path（パス） | True  a| 
リストするldapUserコレクションのID

|===


[[response]]
== 応答

[source]
----
Status: 200, Returns a JSON object representing the stored LDAP resource.
----
[cols="4*"]
|===
| Name | を入力します | 必須 | 説明 


| を入力します | string | True  a| 
リソースのメディアタイプ。定義された値は次のとおりです：

* 「application/astra-ldapUser」




| バージョン | string | True  a| 
リソースのバージョン。定義された値は次のとおりです：

* "1.0"




| ID | string | True  a| 
リソースのグローバル一意識別子。定義された値は次のとおりです：

* UUIDv4スキーマに準拠




| email | string | False  a| 
LDAPユーザーのEメールを表すJSON文字列。定義されている値は次のとおりです：

* 最小長さ：3
* 最大長さ：63




| firstName | string | False  a| 
LDAPユーザーの名を表すJSON文字列。定義された値は次のとおりです：

* 最小長さ：1
* 最大長さ：63




| lastName | string | False  a| 
LDAPユーザーの姓を表すJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長さ：63




| cn | string | False  a| 
LDAPグループ名を表すJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長さ：63




| DN | string | False  a| 
LDAPグループの識別名を表すJSON文字列。定義された値は次のとおりです：

* RFC 4514に準拠




| メタデータ | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
リソースに関連付けられた、クライアントおよびサービス指定のメタデータ。定義された値は次のとおりです：

* Astraメタデータスキーマに準拠


|===
.回答例

====

{
  "type": "application/astra-ldapUser",
  "version": "1.0",
  "id": "2add73ff-89dc-5ff1-be85-39d97549556d",
  "email": "johndoe@example.com",
  "firstName": "John",
  "lastName": "Doe",

    "createdBy": "8f84cf09-8036-51e4-b579-bd30cb07b269"
  }
}
----
====
