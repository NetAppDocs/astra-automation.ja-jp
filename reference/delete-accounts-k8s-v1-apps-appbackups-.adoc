= アプリのアプリケーションバックアップを削除
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/appBackups/{appBackup_id}`#

指定されたアプリケーションバックアップAPIリソースを削除します。進行中のバックアップはキャンセルされ、その後削除されます。

*副作用*

* バックアップが完了すると、バックアップデータは削除されます。




[[parameters]]
== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}




| app_id | string | path（パス） | True  a| 
含まれるアプリリソースのID



| appBackup_id | string | path（パス） | True  a| 
リストするappBackupコレクションのID

|===


[[response]]
== 応答

[source]
----
Status: 204, Indicates if the appBackup resource was deleted.
----
