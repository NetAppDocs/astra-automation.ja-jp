= アプリのアプリケーションスナップショットを一覧表示する
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/appSnaps`#

コレクション内の一致するすべてのリソースのJSON配列を返します。リクエストで個別のフィールドが指定されている場合、アイテムのJSON配列には、一致する各リソースに対して要求されたフィールドが、指定された順序で含まれます。



== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}




| app_id | string | path（パス） | True  a| 
含まれるアプリリソースのID



| 含める | string | query | False  a| 
コレクションを一覧表示する際に、どのフィールドを返すかを指定します。

URLの例："include=id"、"include=id,name"

OpenAPI の例："id"

* 例：id、name、state




| 制限（ Limit ） | string | query | False  a| 
コレクションを一覧表示する際に返されるリソースの最大数を示します。

URLの例："limit=2"

OpenAPI の例："2"

|===

スナップショットにユーザーが指定した名前を含むJSON文字列。指定がない場合、またはスケジュールによってスナップショットが開始された場合、システムはスナップショットに名前を割り当てます。定義された値は次のとおりです：

* 最大長さ：63
* DNS 1123 Label Schemaに準拠




| bucketID | string | False  a| 
スナップショットが作成時に保存される場所を示す、オプションのバケットIDを含むJSON文字列。指定がない場合、クラスター上のデフォルトのバケットが使用されます。クラスター上でデフォルトバケットが指定されていない場合、対応するクラウドのデフォルトバケットが使用されます。クラウドのデフォルトバケットが利用できない場合、作成時にエラーが返されます。定義された値は次のとおりです：

| scheduleID | string | False  a| 
スナップショットがスケジュールによってトリガーされたことを示すオプションのスケジュールIDと、スナップショットをトリガーしたスケジュールを指定するJSON文字列。スケジュールによって開始されたスナップショットの場合にのみ存在します。定義された値は次のとおりです：

* Astra識別子スキーマに準拠




| snapshotAppAsset | string | False  a| 
スナップショットに対応するアプリケーションアセットのIDを含むJSON文字列。このフィールドは、アプリケーションのスナップショットの状態が「completed」になったときに返されます。定義された値は次のとおりです：

* Astra識別子スキーマに準拠




| 状態 | string | True  a| 
スナップショットの動作状態を示す値を含むJSON文字列。定義された値は次のとおりです：

* 「pending」 - アプリケーションのスナップショットは検出のためにスケジュールされています
* 「discovering」 - アプリケーションのスナップショットが検出中です
* 「実行中」-アプリケーションのスナップショットは正常に実行されています
* 「completed」 - アプリケーションのスナップショットが完了しました
* 「failed」 - アプリケーションのスナップショットが永続的な失敗状態にあります
* 「削除済み」 - アプリケーションのスナップショットは現在アクセスできません
* 「削除中」- アプリケーションのスナップショットが削除されています
* 「不明」-アプリケーションのスナップショットの状態を判断できません




| stateUnready | array[string] | True  a|

* 「failed」 - 1つ以上の実行フックが失敗しました
* 「success」 - 適用可能なフックがゼロ個以上あり、すべて成功しました
