= 証明書を削除する
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/certificates/{certificate_id}`#

指定された証明書 API リソースを削除します。



== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}




| certificate_id | string | path（パス） | True  a| 
一覧表示する証明書コレクションのID

|===


== 応答

[source]
----
Status: 204, Indicates if the certificate resource was deleted.
----
