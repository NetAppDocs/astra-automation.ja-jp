= アカウントのすべてのメトリックを取得します
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/metrics`#

アカウントのすべてのメトリックを返します



== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}


|===


== 応答

[source]
----
Status: 200, Returns a OpenMetrics text document containing all metrics for the account.
----

| 詳細 | string | True  a| 



| ステータス | string | True  a| 



| correlationID | string | False  a|
