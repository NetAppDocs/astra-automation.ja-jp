= クラウドのクラスタノードを取得する
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/clouds/{cloud_id}/clusters/{cluster_id}/clusterNodes/{clusterNode_id}`#

JSONレスポンスボディに格納されているクラスタノードAPIリソースを返します。



[[parameters]]
== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}




| cloud_id | string | path（パス） | True  a| 
包含するクラウド リソースのID



| cluster_id | string | path（パス） | True  a| 
含まれるクラスタリソースのID



| clusterNode_id | string | path（パス） | True  a| 
リストするclusterNodeコレクションのID

|===


[[response]]
== 応答

[source]
----
Status: 200, Returns the stored Cluster Node API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | を入力します | 必須 | 説明 


| を入力します | string | True  a| 
リソースのメディアタイプ。定義された値は次のとおりです：

* 「application/astra-clusterNode」




| バージョン | string | True  a| 
リソースのバージョン。定義された値は次のとおりです：

* "1.0"




| ID | string | True  a| 
リソースのグローバル一意識別子。定義された値は次のとおりです：

* UUIDv4スキーマに準拠




| 名前 | string | True  a| 
ノードのKubernetes名を示す値を含むJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長：254




| ロール | string | True  a| 
ノードのKubernetesロールを示す値を含むJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長：254




| ラベル | 配列[link:#labels["ラベル"]] | True  a| 
JSONオブジェクトのJSON配列。各JSONオブジェクトには、ノードに関連付けられたKubernetesラベルが含まれています。詳細情報が利用できない場合、この配列は空になります。

* 最小アイテム数：0




| creationTime | string | True  a| 
ノードが作成された日時を示すISO 8601タイムスタンプを含むJSON文字列。定義値は次のとおりです：

* ISO-8601 Date Time Schemaに準拠




| externalIP | string | True  a| 
ノードの内部IPアドレスを示す値を含むJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長さ：63




| internalIP | string | True  a| 
ノードの外部IPアドレスを示す値を含むJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長さ：63




| ゾーン | string | True  a| 
ノードのKubernetesゾーンを示す値を含むJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長：254




| リージョン | string | True  a| 
ノードのKubernetesリージョンを示す値を含むJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長：254




| instanceType | string | True  a| 
ノードのKubernetesインスタンスタイプを示す値を含むJSON文字列。定義された値は次のとおりです：

* 最小長さ：1
* 最大長：254




| kernelVersion | string | True  a| 
ノードで使用されているカーネルバージョンを示す値を含むJSON文字列。定義値は次のとおりです：

* 最小長さ：1
* 最大長：254




| osImage | string | True  a| 
ノードが使用するオペレーティングシステムイメージを示す値を含むJSON文字列。定義された値は次のとおりです：

* 最小長さ：1
* 最大長：254




| numCpus | string | True  a| 
ノードに割り当てられたCPUの数を示す値を含むJSON文字列。定義された値は次のとおりです：

* 最小長さ：1
* 最大長：254




| memory | string | True  a| 
ノードに割り当てられたメモリ量を示す値を含むJSON文字列。定義された値は次のとおりです：

* 最小長さ：1
* 最大長：254




| 状態 | string | True  a| 
ノードの動作状態を示す値を含むJSON文字列。定義された値は次のとおりです：

* 「running」 - ノードは正常に動作しています
* 「provisioning」 - ノードはプロビジョニング処理中です
* 「discovering」 - ノードの側面が検出されている最中です
* 「pending」 - ノードの検出が予定されています
* 「failed」 - ノードが障害状態です
* 「不明」 - ノードの状態を判断できません




| メタデータ | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
リソースに関連付けられた、クライアントおよびサービス指定のメタデータ。定義された値は次のとおりです：

* Astraメタデータスキーマに準拠
