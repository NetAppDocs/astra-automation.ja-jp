= グループを削除する
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}`#

指定されたグループ API リソースを削除します。

*副作用*

* グループに関連付けられている以下のリソースが削除されます：
* グループを参照するロールバインディング




[[parameters]]
== パラメータ

[cols="5*"]
|===
| Name | を入力します | 入力 | 必須 | 説明 


| account_id | string | path（パス） | True  a| 
包含するアカウントリソースのID

* 例：{{.Account}}




| group_id | string | path（パス） | True  a| 
リストするグループコレクションのID

|===

== 応答
